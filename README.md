# MyMathSteps — website

This repository hosts the published website for **[mymathsteps.com](https://mymathsteps.com)**.

MyMathSteps is a parent-focused math check-in for middle-school students. Families can try a free Grade 6 or Grade 7 check-in, see which skills went well and which to revisit, read worked explanations, and try a bonus practice question for each skill. Parents can create a free account to manage student profiles and save check-in snapshots.

## What's on the site

- **Free check-ins:** sample questions for Grade 6 and Grade 7, with an explanation after every answer.
- **Skill snapshot:** a summary of the topics a student may want to practice.
- **Bonus practice:** one extra skill-matched question with a worked example for each topic.
- **Parent portal:** an optional free account for managing student profiles and saved snapshots.

Grade 8 content and a fuller lesson library are planned.

> Check-ins are early practice snapshots. They are not validated diagnostics or official standardized tests.

## About this repository

This repo contains **only the built website files** (HTML, CSS, JavaScript). It is updated automatically on every release, and the source code is maintained separately.

**Please don't edit files here by hand.** Each deploy replaces the whole repository, so manual changes are overwritten.
